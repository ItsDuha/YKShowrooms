# 🏛️ Showrooms Walk-In System

A centralized web-based platform designed to digitize and manage customer walk-ins, track salesperson follow-ups, monitor staff workloads, and analyze showroom performance.

---

## 🛠️ Technologies Used

### **Backend**

* **Framework:** ASP.NET Core MVC
* **Language:** C#
* **Database:** Microsoft SQL Server
* **ORM:** Entity Framework Core (Database First)
* **Security:** BCrypt.Net (Password Hashing)
* **AI Integration:** Groq API (Models for real-time admin assistance)


### **Frontend**

* **HTML5 & CSS3**
* **Bootstrap**
* **JavaScript**

## ✨ Key Features


### 👤 Visitor Portal

* **Digital Check-In:** Simple form for visitors to submit their details upon arrival.

* **Bilingual Support:** Full support for both English and Arabic.

* **Feedback System:** Star-rating and comment submission post-visit.


### 🛡️ Admin Portal

* **Real-Time Footfall Analytics:** Dashboard cards showing daily, weekly, and monthly visitor counts.

* **Interactive Reports:** Daily walk-in and missed follow-up tracking with search, filters, pagination, and soft-delete/restore features.

* **Staff Management:** Monitors salesperson workload, flags overdue cases, and provides intelligent staffing recommendations.

* **AI Assistant:** Integrated chatbot providing real-time operational insights powered by live system data.
